## 抽样规则

主指令 Step 2 在 6 维矩阵中至少涉及：

- **主动作**：从 `头部动作.md` / `手部动作.md` / `坐姿库/坐姿与站姿.md` 中抽 1
- **微动作**：从 `微动作.md` 中抽 1（且本次输出必须叠加 ≥ 2 个微动作）
- **情绪弧线**：从 `情绪弧线.md` 中抽 1（决定主动作 + 中段 + 收尾的整体节奏）
