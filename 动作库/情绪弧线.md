# 情绪弧线组合

> 把动作和情绪绑定为可复用组合。共 6 条。

## 1. 故作冷淡 → 破功

二郎腿 + 上身微后仰 → 嘴角压不住 → 鼻翼微动 + 偏头

## 2. 神秘出场 → 慢靠近

背对镜头 + 单手撩发（露出颈侧）→ 缓慢转身 → 抬眼看人

## 3. 偏头避开 → 暴露心思

偏头避开 + 下巴微收 → 视线移开 + 咬唇 → 偷看回来 + 鼻息

## 4. 慵懒 → 气场全开

盘腿 + 单手撑脸 + 眯眼 → 缓慢抬眼 → 下巴微收 + 嘴角微抬

## 5. 被撩后强装镇定

肩膀僵直 + 下巴微收 → 眨眼两次 + 视线移开 → 嘴角微抬

## 6. 边笑边骂

肩膀随笑轻动 + 嘴角微抬 → 眯眼 + 鼻息 → 单侧肩膀微抬 + 偏头
