# Demo 002 · 单镜 · 撩发

## 主题

撩发动作组合。10 秒单镜，Tilt 微抬。

## 好在哪

- 起手就是中段（中上半身），给"撩"留出时间
- 撩发 → 咬唇 → 抬眼是一个连贯的动作链
- 末尾抬眼命中镜头，气场全开

## 避免什么坑

- 没有突然爆红的脸颊
- 没有数字变焦
- 没有出现禁用道具（耳麦线只是"手部动作"，画面不出现耳麦）

## 适用场景

- 情绪弧线：神秘 → 魅惑 / 慵懒 → 气场全开
- 主动作：单手撩发 + 抬下巴
- 灯光：黄昏暖光 / 夜晚月光

## 任务卡

```
场景: 主播房-黄昏-暖光
时段: 黄昏 18:00 金黄侧光
弧线: 慵懒 → 抬眼 → 气场全开
主动作: 单手撩发到耳后
微动作: 咬下唇 + 抬下巴
镜头: Tilt 微抬
对白: 你今天怎么这么好看（1 句，骨架 7 暴露心思）
```
