## 使用规则

主指令 Step 1 加载上下文时快速浏览 1–2 个 demo 作为节奏锚点；不直接复用其内容。

## 拓展规则

每次生成后（Step 5 自演化），若本次输出有"特别好的段落"，AI 可选性地把它转写为新 demo 加入 `demo/` 目录。

新 demo 必须：

- 三标签齐全（好在哪 / 避免什么坑 / 适用场景）
- 完整任务卡
- 完整 h3 三段式字段（h3 模式专用 demo）
- 通过 `评估标准.md` 的反例清单
