# Demo 005 · 单镜 · 破功大笑

## 主题

故作冷淡 → 破功弧线。10 秒单镜，Pan 微移。

## 好在哪

- 起手是四分之三侧面，给"破功前"的冷淡留位置
- 中段肩膀随笑轻动，是"破功"的视觉信号
- 收尾的"边笑边骂"用 1 句话收住

## 避免什么坑

- 没有动漫式月牙眼（破功但眼型正常）
- 没有机械式表情切换（冷淡 → 破功是渐变）
- 没有夸张爆笑（笑得有节制）

## 适用场景

- 情绪弧线：故作冷淡 → 被戳中 → 破功大笑
- 主动作：二郎腿 + 上身微后仰
- 灯光：深夜台灯 / 午后日光

## 任务卡

```
场景: 主播房-深夜-台灯
时段: 深夜 23:00 暖黄单点光
弧线: 故作冷淡 → 被戳中 → 破功大笑

微动作: 鼻翼微动 + 肩膀随笑轻动
镜头: Pan 微移
对白: 边笑边骂（1 句，骨架 8 反客为主）
```
