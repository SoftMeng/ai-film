# Demo 003 · 单镜 · 侧坐

## 主题

坐姿 + 偏头组合。10 秒单镜，Static + 微晃。

## 好在哪

- 侧坐 + 膝盖朝向镜头，打破"正面对镜"的僵硬
- 偏头避开 → 偷看回来是经典调情动作
- 起手用二郎腿开场，符合"场景基础"

## 避免什么坑

- 不大特写（始终保持上半身）
- 不用手势撑满画面（手放在膝盖上）
- 没有机械式表情切换（偏头是连贯动作）

## 适用场景

- 情绪弧线：偏头避开 → 偷看 → 暴露心思
- 主动作：二郎腿 + 偏头
- 灯光：午后日光 / 上午侧光

## 任务卡

```
场景: 主播房-午后-日光
时段: 午后 14:00 暖白漫射
弧线: 偏头避开 → 偷看 → 暴露心思
主动作: 二郎腿 + 偏头
微动作: 眨眼两次 + 鼻翼微动
镜头: Static + 微晃
对白: 我本来想……算了（1 句，骨架 5 半句留白）
```
