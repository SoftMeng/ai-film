# Demo 001 · 单镜 · 对视

## 主题

静态对视 + 微表情。10 秒单镜，Static + 微晃。

## 好在哪

- 起手就是上半身，避免全身中景浪费前 2 秒
- 微动作叠加（眨眼 + 嘴角微抬）让画面"有戏"
- 末尾的鼻息留白，给观众想象空间

## 避免什么坑

- 不用大动作，靠眼神传递
- 没有突然爆红的脸颊
- 没有机械式表情切换

## 适用场景

- 情绪弧线：故作冷淡 → 被戳中 → 嘴角压不住
- 主动作：偏头避开 + 偷看回来
- 灯光：夜晚月光 / 深夜台灯

## 任务卡

```
场景: 主播房-深夜-台灯
时段: 深夜 23:00 暖黄单点光
弧线: 故作冷淡 → 被戳中 → 嘴角压不住
主动作: 偏头避开 + 偷看回来
微动作: 眨眼 + 鼻息
镜头: Static + 微晃
对白: 你看我干嘛（1 句，骨架 3 抬杠式）
```
