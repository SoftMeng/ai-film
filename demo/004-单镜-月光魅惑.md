# Demo 004 · 单镜 · 月光魅惑

## 主题

神秘冷光场景。10 秒单镜，Push In 慢推。

## 好在哪

- 冷光 + 月光给"神秘感"打底
- Push In 慢推聚焦表情，不靠动作
- 起手用 Arc Shot 极小弧度暗示"绕过去"的好奇

## 避免什么坑

- 没有突然爆红的脸颊（神秘场景反而要克制）
- 没有任何台灯/落地灯（仅月光）
- 没有数字变焦

## 适用场景

- 情绪弧线：神秘 → 慢靠近 → 魅惑
- 主动作：背对镜头 + 缓慢转身
- 灯光：夜晚月光

## 任务卡

```
场景: 主播房-夜晚-月光
时段: 夜晚 21:00 冷蓝月光
弧线: 神秘 → 慢靠近 → 魅惑
主动作: 背对镜头 + 缓慢转身
微动作: 抬下巴 + 嘴角微抬
镜头: Push In 慢推
对白: 你看什么呢（1 句，骨架 3 抬杠式）
```
