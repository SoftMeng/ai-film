# 对白灵感库 · 总览

> 解决"有趣 + 不重复"。本库是静态资产，不是自动维护的状态文件。

## 子目录

| 文件 | 用途 |
|---|---|
| `调情模式.md` | 8 种调情句式骨架（不是具体台词） |
| `灵感源/` | 4 个方向的入口（热搜/小红书/抖音/流行梗） |
| `对白质检规则.md` | 短/有趣/可改写 四条标准 |

## 使用流程

主指令 Step 3：

1. 抽样一个"灵感方向"（从 `灵感源/`）
2. 用 WebSearch 查最近 1–2 句可改写素材
3. 按 `调情模式.md` 的句式骨架改写为猫神语气
4. 本次会话内自检：不复读上文已出现的句式
5. 写入输出

## 严禁

- ❌ 直接照搬互联网原句（必须改写）
- ❌ 跨语言硬凑（猫神气质要自然）
- ❌ 长句（单句 ≤ 12 字）
