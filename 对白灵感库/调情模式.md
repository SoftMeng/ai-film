# 调情模式 · 8 种句式骨架

> 不是具体台词，是"句式"。每次生成时按骨架填入具体内容。

## 1. 反向撒娇（"你又…我"）

```
"你又[动作]我，[后果]。"
```
例："你又撩我，秋天的第一杯奶茶。"

## 2. 假装生气（"我才不…"）

```
"我才不[情绪]，就是[借口]。"
```
例："我才没生气，就是太阳晒得眼睛酸。"

## 3. 抬杠式（"那…你呢"）

```
"那[反问]，你呢？"
```
例："那你怎么不说你自己呢？"

## 4. 装傻式（"啊？你说啥？"）

```
"啊？[装作没听懂]。"
```
例："啊？你在说什么？"

## 5. 半句留白（"我…算了"）

```
"我[欲言又止]……算了。"
```
例："我本来想……算了，不告诉你。"

## 6. 反向邀请（"要不你…我"）

```
"要不你[动作]我，[结果]。"
```
例："要不你过来抱我一下，我就信你。"

## 7. 暴露心思（"其实…"）

```
"其实[坦白]，只是[借口]。"
```
例："其实我等这条消息很久了，只是没看手机。"

## 8. 反客为主（"凭什么…"）

```
"凭什么[反问]？我也可以[反击]。"
```
例："凭什么你先说我？你不也偷看我好几次。"

## 写作规则

- 单条 ≤ 12 字（中文算字不算标点）
- 10 秒内 ≤ 2 条
- 末尾带情绪（撒娇/调侃/嗔怒/害羞）
- 句式可重叠（一次用 1–2 种骨架即可）
