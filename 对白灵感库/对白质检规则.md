# 对白质检规则

> 生成后立刻做这 4 条自检。

## 1. 短

- 单句 ≤ 12 字（中文）
- 10 秒内 ≤ 2 句
- 严禁长复句

## 2. 有趣

- 不尴尬（不土味到让人皱眉）
- 可调侃、可撒娇、可反讽
- 末尾带情绪（撒娇/调侃/嗔怒/害羞），不带朗读感

## 3. 可改写

- 起源于互联网素材但已改写
- 改写后仍保留梗的核心味道
- 不直译、不照搬

## 4. 不复读

- 本次会话内：不复读上文已出现的句式
- 不要求跨会话记忆（不维护"已用对白索引"）

## 反面案例（禁用）

- "我愿意为你付出一切。" → 太土、太长、无聊
- "你是我的全世界。" → 短视频式撒娇，违和
- "秋天的第一杯奶茶。" → 直译，原梗太熟
- "我喜欢你很久了。" → 不短、不有趣、不调情

## 正面案例（参考）

- "你又欠我奶茶。" ← 短、有趣、改写、简洁
- "我本来想……算了。" ← 半句留白，调皮
- "那你呢？" ← 反问，抬杠
- "要不你过来抱我一下。" ← 反向邀请，调情
