## 一句话机制

**一旦短剧选定人物，全剧 N 个镜头共用同一组外貌描述。** Seedance 在每个镜头里都看到同样的指纹，输出的人物就会一致。

## 指纹字段（精简集 6 项）

| 字段 | 用途 | 示例 |
|---|---|---|
| 年龄段 | 控制视觉年龄感 | 约 25 岁 / 30 出头 / 40 左右 |
| 脸型关键词 | 锚定面部特征 | 瓜子脸 / 方脸 / 圆脸 / 棱角分明 |
| 发型关键词 | 锚定头发样式 | 齐耳短发 / 长直发 / 卷发盘起 |
| 肤色关键词 | 控制肤色 | 偏白 / 自然黄 / 健康小麦 |
| 身高气质 | 控制身形与气质 | 高挑清冷 / 娇小灵动 / 沉稳内敛 |
| 标志特征（可选）| 一眼识别的细节 | 右颧骨小痣 / 眉骨突出 / 戴细框眼镜 |

## 锁定机制

**全剧 N 镜头共用一组指纹。** 写法：把指纹字段直接复制到每个 `创意MV/NNN.txt` 的【演员本体】段开头，作为"长相锚"。

具体动作：先填形象指纹 → 把指纹各字段作为描述性中文，**逐字粘贴**进每个镜头提示词的【演员本体】段最前一行。

## 多角色处理

- **主角指纹**：独立一组，贯穿全剧
- **配角指纹**：每角色独立一组，对手戏镜头同时锁两组
- **群体镜头**：主角指纹 + "若干路人"（不锁个体，只锁主角）

## 与现有 `虚拟演员/` 的关系

字段值**复用现有演员的属性**。从 `虚拟演员/<名字>.md` 抽取时，保持原文措辞风格，不要二次抽象或归并。

## 反向说明（不做什么）

- ❌ 不为指纹建独立文件——指纹随剧本走，剧本在就在，剧本完就丢
- ❌ 不建"指纹字典"——抽到什么用什么，不预生成
- ❌ 不锁死 6 个字段——少于 6 字段（如纯路人戏）也可以工作
- ❌ 不指纹打分——一致性的最终判断权在观众，不在工程

## 配套脚本

本机制的 Python 实现位于 `../scripts/`：

- `drama_schema.py` — DramaConfig / Character / Shot dataclass 强类型校验
- `drama_yaml.py` — 最简 YAML 1.2 子集 frontmatter 解析器
- `drama-new.py` — 建短剧工程骨架（自增编号）
- `drama-shot.py` — 单镜头文件生成（指纹 + 节拍 + 转场自动注入）
- `drama-from-json.py` — JSON 主导端到端桥接（核心入口）
- `drama-lint.py` — 跨镜头一致性 + 节拍 / 转场 / frontmatter 检查（CHECKS 注册表）
- `drama-find.py` — 按 tag / type / applicable 检索短剧 markdown

AI 使用 markdown 时，配合 `python3 scripts/drama-find.py --tag fingerprint` 检索相关文件，不必全文 Read。
