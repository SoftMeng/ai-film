## 一句话机制

**节拍是镜头的情绪位置，不是检查清单。** 每个镜头定一个节拍，整部剧的节拍连起来就是情绪弧线。

## 节拍表（5 个核心节拍）

| 节拍 | 动作倾向 | 镜头倾向 | 情绪关键词 |
|---|---|---|---|
| **期待** | 准备 / 观望 / 进入 | 跟随 / 远景铺垫 | 未知感、可能 |
| **紧张** | 警觉 / 收缩 / 屏息 | 中近景 / 焦点收窄 | 不安、压迫 |
| **释放** | 停顿 / 松弛 / 接触 | 近景 / 细节放大 | 落定、解开 |
| **留白** | 沉默 / 静止 / 凝视 | 特写 / 长镜头 | 余味、空 |
| **收束** | 离开 / 回头 / 淡出 | 远景 / 背影 / 缓推 | 闭合、回响 |

## 弧线约定（选用建议）

N 镜短剧的节拍分布仅作**建议**，故事决定节拍：

| 镜头数 | 推荐节拍走向 |
|---|---|
| 3 镜 | 期待 → 紧张 → 释放 |
| 5 镜 | 期待 → 紧张 → 释放 → 留白 → 收束 |
| 8 镜 | 期待 → 紧张 → 紧张 → 释放 → 释放 → 留白 → 留白 → 收束 |

节拍可重复、可省略、可调序——只看情绪弧线是否闭合（首尾不矛盾）。

## 节拍标定方法

每个 `创意MV/NNN.txt` 的【整体风格】段开头加一行情绪节拍标注，例如：

```
【整体风格 · 节拍：紧张】
电影感都市夜景，写实质感。...
```

该标注写在【演员本体】之前，作为该镜头的情绪定位。节拍值取自上表。

## 与 `剧本层.md` 的关系

剧本四段式中的 `feel-arc` 段直接引用本表。例如 `feel-arc：期待 → 紧张 → 释放 → 留白 → 收束`，其中每个节拍的名字都来自本文件。

## 反向说明（不做什么）

- ❌ 不写强制条款——本文件是"选用建议"，不是"必须遵守"
- ❌ 不锁死 5 个节拍——故事需要时可新加（如"惊吓"、"释怀"）
- ❌ 不要求每个节拍都出现——3 镜短剧可以省"留白"，5 镜也可以不"收束"
- ❌ 不规定节拍如何转场——切点机制见 `镜头切换.md`
