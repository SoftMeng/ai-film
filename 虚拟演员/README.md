## 装扮层（与演员完全解耦）

可换装扮（发型结构/妆容/美瞳/服装/鞋履/饰品）在 `../化妆间/` 目录下，**1 装扮 1 文件**。

任意演员可穿戴任意装扮。演员与装扮之间没有绑定关系。

## 命名约定

- **演员人设文档** = `<真名>.md`（顶层）
- **装扮文档** = `../化妆间/<人物形象>.txt`

## 扩展

新增虚拟演员时，建 1 个文件：

1. `<新真名>.md`（物理生理特征 + 内在设定）

新增装扮时，建 1 个文件：

1. `../化妆间/<新人物形象>.txt`（装扮层）
