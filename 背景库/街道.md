# 街道

> 老上海/海派 + 复古法式/日杂清新混合的临街步行视角
> 维度：7

## 基调

低饱和暖色 + 米白 + 莫兰迪绿/雾霾蓝点缀；木质店招与手写字体；不开霓虹、不出现强反光玻璃幕墙。

## 地面铺装

- 主路：深灰色沥青，无明显标线
- 人行道：灰色水泥砖 或 米色/灰色彩色透水砖
- 路沿石：浅灰色花岗岩
- 沿街店铺前：可设窄条木平台（外摆延伸），与砖面齐平
- 排水：路沿侧设隐形排水沟

## 边界与设施

- 路灯：黑色 / 深灰色铸铁造型，2–3 m 间距
- 长椅：木质条凳 + 铸铁腿，沿树荫摆放
- 邮筒：复古铸铁邮筒 或 现代不锈钢款（颜色统一）
- 报刊亭：木质/铝合金小亭（如有）
- 共享单车停放区：浅色标线划定

## 主体陈设（临街店铺底层）

- 玻璃橱窗：白色金属框 或 木框，1.5–2 m 高
- 折叠门：木质窄条折叠门（如西式面包店/茶饮店）
- 门把手：黄铜 / 木质把手
- 阳台（如二楼）：铸铁栏杆 + 攀藤植物
- 外摆：2–4 张小圆桌 + 藤椅/木椅（不挡通行）

## 绿植与行道树

- 行道树：法国梧桐 / 银杏 / 樟树，树干直径 20–40 cm
- 街边花箱：长条形石质/铁艺花箱，种低维护草花（矮牵牛 / 鼠尾草）
- 绿篱：修剪整齐的黄杨 / 女贞球，置于店铺前
- 攀藤：凌霄 / 常春藤，沿二层栏杆下垂

## 招牌与立面

- 店招：木质手写黑板 或 木质刻字招牌；字体手写体（不出现具体品牌名）
- 侧招：金属冲孔招牌（夜间透光）
- 橱窗陈列：陶瓷器皿 / 木质面包架 / 干花 / 旧书（按店铺业态）
- 立面材质：米色/灰色涂料 + 局部红砖 + 木质雨棚
- 海报：≤ 1 张手写告示（不含品牌商标）

## 空间关系

- 建筑与路沿距离 0–1.5 m（贴线建筑）
- 人行道通行宽度 ≥ 3 m
- 外摆区距路沿 ≥ 0.6 m（留出入通道）
- 路灯与行道树交替排列，间距 5–8 m
- 街角设小型集散广场（圆角过渡）

## 严禁

- ❌ 拥挤摊贩占道
- ❌ 霓虹灯招牌 / 强光广告牌
- ❌ 强反光玻璃幕墙 / 镜面外墙
- ❌ 满墙小广告 / 城市牛皮癣
- ❌ 具体品牌名 / 商标（如星巴克、可口可乐）
- ❌ 高饱和强对比涂装
- ❌ 车流密集 + 堵车场景
- ❌ 暴晒无任何遮阴

## 变体钩子

下一个街道变体（-上海老弄堂 / -成都老街 / -日式清新 / -港式复古）可直接复制本骨架，按风格调"招牌与立面 / 主体陈设"两段即可。
