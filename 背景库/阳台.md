# 阳台

> 自然休闲风 · 防腐木 + 绿植 · 治愈角落
> 维度：7

## 基调

浅木色 + 灰白 + 绿植点缀；自然风 / 莫兰迪色系；主色与点缀色按 7 : 3 比例（如米白 + 墨绿 / 焦糖）。

## 墙面与地面

- 地面：防腐木地板（主）+ 鹅卵石点缀（拼接带，宽 ~10 cm）
- 墙面：防水涂料刷拼色 / 防腐木墙板 / 纯白乳胶漆
- 排水：地漏隐藏在鹅卵石下
- 顶面：白色 / 浅木色，防腐木吊顶可选

## 家具

- 主椅：天然藤椅 / 竹编椅 / 浅木矮桌（直径 50–80 cm）
- 副椅：金属框架 + 棉麻坐垫单椅 或 布艺沙发床（小阳台可伸缩款）
- 桌几：圆形 / 方形浅木小桌，可折叠款
- 收纳：防腐木栅格 + 垂吊植物角；编织篮（水泥盆外裹）

## 窗与光

- 栏杆处：可绕 LED 灯串（仅夜景点缀，不作主光）
- 壁灯：北欧风纸质灯笼 / 工业风铁艺灯（3000K 暖光）
- 顶面：内嵌式防水射灯（封闭阳台）

## 绿植

- 墙挂：防腐木栅格 + 垂吊植物（常春藤 / 空气凤梨）
- 地面大型：龟背竹 / 虎皮兰 / 散尾葵
- 小盆栽：多肉组合 / 薄荷 / 迷迭香（窗台）
- 花架：防腐木阶梯花架，靠墙 1–2 个

## 装饰与物件

- 地面：剑麻编织地毯 / 仿草坪 PVC 地毯
- 桌面：陶瓷花插 / 木托盘 / 蜡烛 1 个
- 墙面挂件：铁艺网格（照片 / 干花 / 小盆栽）
- 抱枕：防水面料，墨绿 / 焦糖 / 米白 2–3 个

## 空间关系

- 防腐木地板与鹅卵石带分区，鹅卵石靠墙或角落
- 绿植角与休闲区分开（各占一面墙）
- 桌椅靠栏杆或角落摆放，留出走道
- 西晒阳台加强遮光（亚麻卷帘 + 防晒植物）
- 5㎡ 以下阳台优选轻量化家具

## 严禁

- ❌ 千篇一律瓷砖地面（无设计感）
- ❌ LED 灯串过密堆叠
- ❌ 卡座占满小阳台（2–3㎡ 慎选）
- ❌ 全封闭式玻璃房（失去自然感）
- ❌ 楼下晾衣区未做防水
- ❌ 网红拱形门洞堆砌

## 变体钩子
