# 咖啡馆外摆

> 欧式露天 / 复古 / 现代工业混合的临街咖啡外摆区
> 维度：7

## 基调

暖木 + 黑色金属 + 绿植；中柱遮阳伞 + 折叠桌椅；开方式布局；不出现具体品牌名 / 商标。

## 地面铺装

- 主铺：防腐木平台 / 灰色石板 / 红砖铺地
- 与街道衔接处：路沿石过渡 + 装饰灯串沿边
- 收边：铁艺收边条 / 浅色石材压顶
- 排水：地漏设于外摆区边缘（不外露）

## 边界与设施

- 路沿石：浅灰色花岗岩，与街道铺装齐平
- 花箱围栏：长条形防腐木花箱 + 草花组合（鼠尾草 / 矮牵牛）
- 装饰灯串：3000 K 暖光，沿伞骨或花箱上方布置（≤ 3 串）
- 菜单板：A 字型木质黑板 + 黄铜支架，置于路沿一侧
- 入口标识：木质立牌 或 帆布道旗 ≤ 2 面（不含品牌名）

## 主体陈设

- 中柱遮阳伞：直径 3.0–3.6 m，伞面米白/沙色/雾霾蓝，UPF 50+
- 伞骨：8 根以上钢骨，伞杆高度 2.4–3.2 m
- 伞底座：≥ 25 kg（混凝土/沙袋固定）
- 折叠桌椅：铁艺圆桌（直径 60–70 cm）+ 藤编 / 木质餐椅 4–8 把
- 落地菜单架 / 陶瓷花瓶 / 桌面小型绿植（≤ 3 件）

## 绿植

- 大型盆栽：橄榄树 / 琴叶榕 / 旅人蕉，伞与伞之间或区域四角
- 花箱草花：低维护组合（鼠尾草 / 矮牵牛 / 常春藤垂吊）
- 桌面小型：薄荷 / 多肉 / 蕨类小盆栽
- 攀藤：常春藤 / 凌霄，沿墙面或栏杆下垂（条件允许时）

## 招牌与立面

- 店面招牌：木质手写黑板 + 黄铜边框（如有）
- 帆布道旗：≤ 2 面，米白底深色手写体（不含品牌名）
- 墙面爬藤：常春藤 / 凌霄（条件允许）
- 橱窗：大面积玻璃橱窗，可见店内吧台
- 雨棚：亚麻卷帘 / 木质挑檐（防晒）

## 空间关系

- 外摆区与街道间留 ≥ 0.6 m 通道
- 伞间距 ≥ 1.5 m（不互相遮挡）
- 单伞下座位 4–6 椅
- 外摆区前设路沿石过渡（不直接侵占车道）
- 花箱围栏包围外摆区 3–4 面（入口侧开口）

## 严禁

- ❌ 软骨伞（抗风差，易倒）
- ❌ 暴晒无遮阴
- ❌ 具体品牌名 / 商标（如星巴克）
- ❌ 道旗密布遮挡视线
- ❌ LED 灯串过密堆叠
- ❌ 外摆占用人行道盲道
- ❌ 高饱和色伞面 / 塑料感过强材质
- ❌ 与车道无任何物理隔离
