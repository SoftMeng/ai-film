# 浴室

> SPA 极简风 · 自然材质 · 米灰白 · 干湿分离
> 维度：7

## 基调

白 + 米色 + 灰色 + 浅木点缀；自然色系（米色调 / 灰色 / 花岗岩色 / 炭灰）；木质与混凝土/大理石混搭。

## 墙面与地面

- 墙面：大块天然石材瓷砖（板岩 / 花岗岩 / 砂岩纹理）或 仿木地板瓷砖
- 淋浴区：彩色马赛克 / 几何 / 花卉瓷砖做视觉焦点（≤ 1 面墙）
- 地面：天然石材 / 大理石 / 防滑炻瓷砖
- 冷感现代可选：水泥质感饰面（灰色 / 自然色调），可完全不用瓷砖

## 浴缸与淋浴

- 主浴缸：独立式（方形 / 椭圆形 / 船形），搭配高脚落地龙头
- 副浴缸（小浴室）：转角浴缸
- 淋浴：步入式 + 玻璃 / 有机玻璃隔断 + 雨淋花洒
- 地面齐平式淋浴区（无门槛）
- 干湿分离：玻璃隔断 或 一道低矮挡水条

## 家具与台盆

- 台盆：悬浮式木质 / 天然石材台盆，无把手柜体
- 镜柜：内置 LED 照明镜子，无把手简约设计
- 收纳：嵌入柜 + 底柜 + 高柜 + 边柜（多层次）
- 毛巾架：横杆式加热架 / 木梯式收纳架

## 窗与光

- 主光：嵌入式 LED 筒灯 / 暗装射灯（3500–4000K）
- 镜前：LED 灯带 / 镜灯（≥ 90 CRI 还原肤色）
- 暗装式龙头：淋浴和浴缸控制面板嵌入墙体
- 无窗浴室：镜柜内置 LED + 灯带补光

## 装饰与物件

- 龙头 / 花洒：设计款镀铬 / 拉丝金属（作为艺术品存在）
- 绿植：1 盆悬挂蕨类 / 1 盆小型虎尾兰（浴室耐湿）
- 毛巾：白色 / 米色 / 浅灰纯色，厚织
- 配件：陶瓷皂液器 / 玻璃杯 / 木质托盘（≤ 5 件）

## 空间关系

- 淋浴区与浴缸分离（提升舒适度与灵活性）
- 悬浮柜下方留空（便于清扫）
- 镜柜正对台盆
- 马桶独立小间 或 与洗漱区以矮墙分隔
- 落地窗引入花园景致（条件允许时）

## 严禁

- ❌ 全瓷砖堆砌（无焦点 / 无层次）
- ❌ 复杂雕花龙头（与简约基调冲突）
- ❌ 全透明淋浴无隔断（水花外溅）
- ❌ 暗卫无机械通风
- ❌ 冷感水泥 + 冷白光（失去 SPA 感）
- ❌ 彩色马赛克满墙堆砌
- ❌ 浴缸与马桶面对面（≤ 30 cm）

## 变体钩子

下一个浴室变体（-日式温泉 / -复古英伦 / -工业水泥 / -北欧原木）可直接复制本骨架，按风格调"墙面与地面 / 装饰与物件"两段即可。
