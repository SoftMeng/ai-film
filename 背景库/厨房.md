# 厨房

> 现代简约风 · 雾面质感 · 隐藏收纳 · 米杏奶油色系
> 维度：7

## 基调

米杏色 / 奶油灰 / 蜂蜜金低彩度色基底；雾面石英 + 亮面大理石 + 玻璃背板异材质组合；极简线条，线性无把手柜体。

## 墙面与地面

- 墙面：白色 / 浅灰亮面瓷砖 或 大理石立面（防溅墙）
- 地面：灰纹瓷砖 / 浅橡木色地板；中岛与橱柜地坪色连贯
- 墙面瓷砖：纯色或浅纹，无小花砖堆砌

## 橱柜与台面

- 门板：米杏色 / 纯白雾面烤漆，线性无把手或嵌入式 C 把手
- 台面：白色石英 / 赛丽石 / 浅灰岩板（45°倒角）
- 中岛：一整延伸设计，与橱柜同色系或同地坪纹理
- 家电墙：烤箱 / 蒸炉 / 冰箱嵌入柜体，雾面烤漆 + 香檳金把手

## 窗与光

- 主窗：白色纱帘 或 浅木百叶
- 吊柜下：LED 灯条（仅作业面补光）
- 中岛上方：2–3 盏极简吊灯（线性 / 球形）
- 全屋色温 3500–4000 K，作业面 4000 K 提亮

## 家具与电器

- 中岛：高 90 cm 操作面 + 高 105 cm 吧台面（高低台）
- 吧凳：2–3 把，浅木 / 金属 / 皮质混搭
- 收纳：抽屉式 / 升降柜 / 调味侧拉 / 刀叉盘
- 开放收纳区：吊挂杯具 / 花艺 / 藏酒展示（≤ 30% 柜面）

## 装饰与物件

- 墙面：1 块大理石或岩板防溅墙 + 1 个小型磁吸刀架 / 挂杆
- 台面：1 个木砧板 / 1 个陶瓷调料罐组 / 1 个小型绿植（薄荷 / 迷迭香）
- 中岛：1 个藤编 / 陶瓷面包筐 + 1 个托盘
- 窗台：1 盆小型香草盆栽

## 空间关系

- 橱柜沿墙 L 型 / 一字型排布
- 中岛与橱柜之间通道 ≥ 1.2 m
- 冰箱 / 烤箱嵌入家电墙，与操作台动线连续
- 水槽靠窗（自然光下洗菜）
- 灶台远离冰箱（热源隔开）

## 严禁

- ❌ 高饱和彩色门板 / 跳色面板
- ❌ 复杂雕花把手 / 复古铜把手（与简约基调冲突）
- ❌ 开放式杂物堆放（必须藏入柜体）
- ❌ 油烟机外露无包裹
- ❌ 小花砖满墙堆砌
- ❌ 全屋深色（与"米杏奶油"基调冲突）

## 变体钩子

下一个厨房变体（-北欧原木 / -日式原木 / -复古 / -工业）可直接复制本骨架，按风格调"橱柜与台面 / 装饰与物件"两段即可。
