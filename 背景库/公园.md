# 公园

> 海派园林 + 复层种植 + 边界后退的当代城市公园
> 维度：7

## 基调

自然系绿 + 米色园路 + 灰白铺装；复层种植（乔木 + 灌木 + 地被）；木质指示牌与石刻园名；不开网红打卡装置堆砌。

## 地面铺装

- 主园路：青石板 / 灰色透水砖 / 水泥压模地坪，路宽 2.4 m
- 次园路：碎石 / 卵石 / 木屑小路，路宽 1.2–1.6 m
- 草坪：开阔中央大草坪 + 林下缀花草坪
- 水体：荷花池 / 浅水溪涧 / 雨水花园
- 休憩节点：石板平台 / 防腐木平台

## 边界与设施

- 园墙：虚实结合漏窗墙 / 砖砌矮墙 / 钢制栏杆（边界后退 3–12 m）
- 园椅：防腐木条凳 + 石基 / 铸铁腿木椅
- 路灯：低矮草坪灯 + 高杆庭园灯（造型统一）
- 标识牌：木质立柱指示牌 / 嵌入式石刻
- 垃圾桶：木质外壳 + 金属内胆，按 50 m 间距
- 公共设施：公厕 / 饮水点 / 紧急呼叫柱

## 主体陈设

- 凉亭：单檐 / 重檐木亭 或 当代钢结构景观亭（不出现雕梁画栋）
- 雕塑：抽象/写实雕塑 ≤ 2 件（基座 ≤ 1.2 m 高）
- 健身设施：缓坡塑胶地坪 + 椭圆机 / 漫步机 / 拉伸器
- 茶室：木质/钢结构景观建筑，低矮曲面屋顶
- 儿童活动区：沙池 + 滑梯 + 攀爬架（≤ 50 ㎡集中布置）

## 绿植与行道树

- 乔木：香樟 / 银杏 / 法国梧桐 / 雪松 / 桂花（季相变化）
- 中层：玉兰 / 海棠 / 紫薇 / 木槿（观花）
- 灌木球：黄杨球 / 红叶石楠球 / 龟甲冬青
- 地被：麦冬 / 玉簪 / 鼠尾草 / 矮牵牛
- 水生：荷花 / 睡莲 / 菖蒲 / 再力花
- 攀藤：凌霄 / 紫藤 / 常春藤（凉亭/廊架覆盖）

## 招牌与立面

- 园名标识：石刻园名嵌于入口门楼 或 景石刻字
- 指示牌：木质立柱 / 钢制立柱（统一风格）
- 解释牌：木质框架 + 透明面板（植物介绍 / 园区地图）
- 海报：≤ 1 张活动告示（不含品牌名）
- 涂鸦：限定区域墙绘（其余保持素净）

## 空间关系

- 主园路串联 5–7 个特征片区（南园 / 北园 / 茶室区 / 健身区 / 草坪区 等）
- 一级园路与二级园路形成环路（不出现死胡同）
- 边界后退：临街界面退让红线 3–12 m（缓冲噪音与尾气）
- 休憩点沿园路每 100–150 m 设一处
- 入口宽度 20–30 m（弱化园墙存在感）

## 严禁

- ❌ 大面积混凝土水刷石无序堆砌
- ❌ 网红拱门 / 网红秋千 / 网红鸟巢堆砌
- ❌ 灯杆过密（夜空光污染）
- ❌ 全开放界面无缓冲（直面高架路车流）
- ❌ 具体商业品牌名 / 商业广告
- ❌ 草坪全开放可踩踏（应设汀步或围栏）
- ❌ 水体无护栏（儿童安全隐患）

## 变体钩子

下一个公园变体（-英式花园 / -法式规整 / -日式枯山水 / -中式传统）可直接复制本骨架，按风格调"地面铺装 / 主体陈设 / 绿植与行道树"三段即可。
