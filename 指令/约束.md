# 约束层 · Constraints

> 全工程范围的**硬约束与底线**。只承载 AI 视频模型与平台层客观规则（与风格无关），不涉及具体形象/场景/动作/对白（这些在各专属文件）。

## 1. 真实感约束机制化

> 把"严禁项"改写为可执行的机制描述。

| 严禁现象 | 机制描述（执行方式） |
|---|---|
| 机械式表情切换 | 表情渐变 ≥ 1.2 秒，每次表情包含 ≥ 2 个微动作（眨眼/嘴角微动/呼吸起伏） |
| 突然爆红的脸颊 | 肤色升温允许非常轻微/缓慢/不均匀，或完全不出现明显红晕 |
| 均匀粉色腮红 / 害羞特效 | 不允许出现任何粉色滤镜；害羞通过视线移开/嘴角压不住/手部停顿/身体侧开表现 |
| 动漫式月牙眼 | 真实眼型；仅允许自然眯眼/未完成完成的笑 |
| 塑料皮肤 / 美颜磨皮 | 保留毛孔、细小面部起伏、自然肤色差异 |
| 多余手指 | 每只手严格 5 指 |
| 换脸 / 换装 | 严格保持参考图身份、五官、脸型、发型、发色、体型、服装、气质 |
| 数字变焦 | 1× 主摄视角，全程轻微手持微晃 + 拍摄者呼吸起伏 |
| 镜头瞬移 | 景别顺序：全身中景 → 上半身 → 半身近景 → 上半身，全程不切镜 |
| 人像模式边缘错误 | 使用真实手机景深，背景自然柔化但保留层次 |
| 无字幕 / 滤镜 / 美颜 / 磨皮 / 特效 / 背景音乐 | 全程零后期叠加 |
| 大特写填满画面 | 最近景别必须保留头顶、双肩、颈部、部分胸口 |

## 2. 默认画幅与镜头原则

> 用户无倾向画幅与镜头时，按照【默认画幅与镜头原则】处理

- **画幅**：竖屏（9:16）— 在景别描述中体现
- **时长**：严格 10 秒
- **景别顺序**：全身中景 → 腰部以上上半身 → 胸口以上半身近景 → 完整上半身
- **视角**：1× 主摄（无超广角畸变、无长焦偷拍质感）
- **手持微晃**：全程带轻微手持微晃 + 拍摄者呼吸起伏
- **不切镜**：所有时间段是同一镜头的连续表演阶段，不是切镜
- **距离约束**：10 秒内主体与镜头最近距离 ≥ 1.2 米。在 `<Subject 1>` 描述中显式声明初始距离。**禁止使用"zooms in"或"pushes in"等任何放大动作**。

## 5. 反机械感写作约束

> 不替代第 1–3 节的真实感硬约束与工程底线。本节只解决"组件对、读起来像清单"的问题。

- **动词优先名词**：每段用动词起句（如"胯开始画 8 字""重心后坐"），不用名词罗列起句（如"胯部""重心"）。
- **避免连续 3 个并列短语**：连续短句不超过 2 句，第 3 句起要承接或转折；不允许"<动作>...<动作细节>...<微动作>..."的并列槽位结构（详见 `模板/Seedance-中文结构.md`）。
- **每段至少 1 个节奏词或镜头隐喻**：如"轻轻""一堵墙""拖出一道""对焦""收成一个……的结尾"，让段落有体感而非参数表。
- **不写解剖学姿势描述**：把"胯部向左后方放重心约 40°"改写为身体感受或视觉意象（"胯向左后坐下去"）。
- **每段自问三问再下笔**——这段推进什么？与上段什么关系？结束时观众应感受到什么？三问无答案则重写。
