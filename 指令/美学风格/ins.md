# ins.md · INS 风格档案

> Instagram Aesthetic · 跨场景美学语言档案 · 可与任意背景/演员/动作叠加
> 维度：8

## 1. 美学方向

INS 风是 Instagram 平台沉淀下来的"低饱和 + 留白 + 触感"视觉语言。**强调可触摸的质感、严格的色彩管理、有秩序的版式**，与单一场景无关，可与任意背景库文件、任意演员、任意妆造叠加。

## 2. 颜色基调

- 核心色系：**莫兰迪色系 / 单色系渐变**（高灰度 + 低饱和 + 中高明度）
- 常用基色：
  - 米白（Pantone 7527 C 风）
  - 奶油色 / 燕麦色
  - 雾霾蓝 / 薄荷绿 / 灰粉
- 配色规则：
  - 主色占比 60% / 辅色 30% / 点缀色 10%
  - 严格控制色相 ≤ 3 个
  - 避免任何高饱和 / 纯黑 / 荧光

## 3. 光线语言

- **柔光 / 漫射光 / 无强光反差**
- 自然光（窗光 / 阴天散射光）优于直射光
- 阴影柔化，不出现锐利边界的硬阴影
- 不出现聚光灯、追光、舞台灯
- 不出现冷白光 / 强暖光反差 / 霓虹色光

## 4. 常用元素词（写作时作为后缀）

- 材质：棉麻 / 亚麻 / 藤编 / 牛皮纸 / 哑光 / 触感纸 / 拉丝金属
- 工艺：哑光覆膜 / 局部 UV / 烫哑金 / 凹凸压印
- 排版：8pt 网格 / 12pt 基线网格 / 1.5 倍留白 / 不对称平衡 / 黄金分割
- 字体：无衬线体（Helvetica Neue Light / 思源黑体 Light 调）
- 摄影：浅景深 / 自然光 / 生活场景 / 留白 ≥ 1/3 画面

## 5. 推荐背景范围

与下列 `背景库/*.md` 文件搭配最自然：
- `少女INS风卧室.md`（同名直接对应）
- `起居室.md`（极简现代段可叠加）
- `咖啡馆外摆.md`（米色 / 木质 / 中柱伞段）
- `街道.md`（木质店招 / 莫兰迪绿明档段）
- `阳台.md`（浅木 + 草编坐墩段）
- `公园.md`（海派园林 + 素净段）

避免：浴室（金属冷感强）、厨房（功能性段）——除非用户明确要求。

## 6. 推荐妆造范围

下列 `化妆间/*.txt` 名称关键词命中可优先：
- 含「缎面 / 米白 / 杏色 / 清新少女 / 慵懒冷调 / 芭蕾薄荷绿」
- 配色低饱和、不出现霓虹/赛博/舞台元素
- 妆容自然（无重眼影 / 无高光闪片堆叠）

具体由 AI 在写作时根据风格后缀词判定，不做硬列表。

## 7. 专属禁止（仅本风格内有效）

- ❌ 高饱和 / 强对比 / 荧光色
- ❌ 霓虹灯 / 赛博 / 数字像素风
- ❌ 舞台灯 / 聚光灯 / 追光
- ❌ 直播设备 / 小道具
- ❌ 镜面玻璃幕墙反光
- ❌ 居中对称版式 / 满版信息堆叠
- ❌ 重眼影 + 闪片 + 假睫毛组合

## 8. 与工程硬约束的关系

- `指令/约束.md` 的真实感机制化（表情渐变/手指/美颜/字幕/换装等）**永久生效**，不因本档案而放宽
- 本档案只在「美学语言 / 视觉风格」维度生效，与真实感约束叠加

## 9. 变体钩子

下一个 INS 变体（-法式 / -韩系 / -日式 / -复古）可直接复制本骨架，按风格调"颜色基调 / 光线语言 / 常用元素词"三段即可。

或新建完全不同体系：古风 / 赛博 / 黑白极简 / 油画质感……各自独立成档。
