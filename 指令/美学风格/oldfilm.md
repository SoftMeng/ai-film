# oldfilm.md · 老电影风格档案

> 民国上海 + 港片复古 + 黑白默片 · 故意做旧颗粒 · 棕褐色调 · 弄堂市井
> 维度：8

## 1. 美学方向

老电影的「**故意做旧胶片颗粒 + 民国色调 + 弄堂市井**」美学语言。**核心是"上海摩登"的时代质感**——1920-30 年代上海、含蓄简洁的影像语言、近乎完美的早期摄影构图、神怪古装或市井喜剧。10 秒片段聚焦于"被时代质感包裹的瞬间"，保留所有老式摄影机的颗粒与光晕。

## 2. 颜色基调

- **民国色调**（与 cinema 干净胶片色、documentary 自然色形成第六象限）
- 核心色系：
  - 棕褐 / 米黄 / 旧纸色（默片 / 早期彩色片）
  - 烟青 / 墨绿（《神女》《盘丝洞》色调）
  - 复古招牌的红绿金（弄堂烟纸店霓虹）
- 配色规则：
  - **故意降低色彩饱和度**到接近黑白
  - **保留胶片颗粒感**（不是数字摄影机的纯净画面）
  - 暗部偏棕褐（老式显影液的暖调）
  - 整体偏旧偏黄，不追求现代数码鲜艳

## 3. 光线语言

- **早期摄影机美学**（柔光、对比度低、高光易爆）
- 自然光独大：窗户光 / 油灯光 / 老式电灯光（《神女》《都市风光》典型布光）
- 室内布光偏暖黄（油灯时代延续）
- 不用冷白光 / 强暖白光反差 / 现代 LED 灯具
- 暗部偏暖棕（不是冷蓝）
- 高光允许轻微过曝（早期胶片特性）

## 4. 常用元素词（写作时作为后缀）

- 视觉：**故意做旧胶片颗粒** / 棕褐色调 / 默片构图 / 近乎完美的影像语言
- 摄影：固定机位 / 静态构图 / 中远景为主 / 特写仅用于关键物件（如《神女》的脚部特写）
- 时代：弄堂市井 / 烟纸店霓虹 / 老式招牌 / 西洋默片手法 / 月份牌画美学
- 节奏：极慢 / 不卡点 / 让场景自然展开 / 默片式表演（夸张但克制）
- 镜头畸变：轻微桶形畸变（早期镜头特征）

> ⚠️ **与 cinema 的关键差异**：
> - cinema = **干净胶片**（侯孝贤长镜头，无颗粒感）
> - oldfilm = **故意做旧颗粒**（默片/早期彩色片，明显颗粒与偏色）
> 两者完全不同——cinema 是现代电影感的胶片，oldfilm 是 1920-30 年代老式摄影机的真实质感

## 5. 推荐背景范围

与下列 `背景库/*.md` 文件搭配效果最佳：
- `街道.md`（老上海/海派街道 +木质店招 + 海派老弄堂）—— 老电影核心场景
- `咖啡馆外摆.md`（若指民国咖啡馆，可改造；若指现代外摆则跳过）
- `起居室.md`（老式家具 + 油灯 + 民国留声机）

避免：`公园.md`（自然系）、`少女INS风卧室.md`（现代风）、`厨房.md`（功能性过强）。

## 6. 推荐妆造范围

下列 `化妆间/*.txt` 名称关键词命中可优先：
- 含「红汉服 / 盛唐汉服 / 旗袍 / 紫金仙侠 / 中式幻想 / 国潮」—— 时代感强
- 含「古风 / 仙姬 / 仙侠」—— 神怪古装片美学
- 整体偏旧时代质感、不追求现代时尚

具体由 AI 在写作时根据风格后缀词判定。

## 7. 专属禁止（仅本风格内有效）

- ❌ 抖音爆款的高饱和撞色（与 douyin 风混淆）
- ❌ Instagram 的莫兰迪淡彩（与 ins 风混淆）
- ❌ 干净胶片色（与 cinema 风混淆）
- ❌ 自然真实色（与 documentary 风混淆）
- ❌ 现代霓虹 / LED 灯光
- ❌ 大特写填满画面（默片时代无此风格，最近距离 ≥ 1.2 米）
- ❌ 数字变焦 / 镜头瞬移
- ❌ 现代运动镜头 / 快速剪辑节奏

## 8. 与工程硬约束的关系

- `指令/约束.md` 的真实感机制化（表情渐变 ≥ 1.2 秒 / 不切镜 / 1× 主摄）**永久生效**
- 本档案与约束.md **天然兼容**——固定机位 + 不切镜 + 早期摄影机美学正是约束.md 的延伸
- 重要：老电影的"默片表演"虽夸张但克制——不是抖音爆款的夸张，是默片时代受无声表演限制的克制夸张
- 「弄堂市井 / 烟纸店霓虹」是 1920-30 年代上海的标志性元素，AI 在写作时应主动调用
