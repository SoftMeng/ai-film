# documentary.md · 纪录片风格档案

> BBC 自然纪录片 + 人文纪实 · 手持真实呼吸感 · 大景深 · 长时间跟踪
> 维度：8

## 1. 美学方向

纪录片的「真实自然 / 大景深 / 长镜头跟踪 / 真实环境」美学语言。**核心是"完全真实的大自然"**——不靠滤镜、不靠后期、不靠戏剧化布光，靠摄影师真实深入环境长时间蹲守拍摄。10 秒片段聚焦于一个"被记录的真实瞬间"，保留所有真实的呼吸感与微抖。

## 2. 颜色基调

- **真实自然色**（与 ins 莫兰迪、douyin 高饱和、cinema 胶片色形成第四象限）
- 核心色系：
  - 自然绿 / 泥土棕 / 岩石灰（自然环境）
  - 天空蓝 / 海水蓝（户外天空水面）
  - 室内暖黄（自然光透窗的暖调）
- 配色规则：
  - 不追求统一色调——同一画面可有多种自然色共存
  - 动态范围宽（高光不爆、暗部不死）
  - 摄影机感光器承受极广光线范围（从深海到沙漠皆可）

## 3. 光线语言

- **完全真实光**（不布光、不打光）
- 自然光独大：日出 / 日落 / 阴天 / 月光 / 室内窗户光
- 允许微光拍摄（深海 / 夜景用高感光度摄影机）
- 不使用任何舞台灯 / 追光 / 聚光 / 闪光灯
- 不用冷白光 / 强暖白光反差
- 暗部保留细节（真实环境中的暗部即暗部）

## 4. 常用元素词（写作时作为后缀）

- 镜头：**手持真实呼吸感**（微晃幅度大于 cinema 的极缓推进） / 长镜头跟踪 / 大景深 / 浅景深快速切换（动物摄影）
- 摄影机：RED 6K / Amira / 微光摄影机 / 间谍伪装镜头
- 拍摄周期：长时间蹲守 / 多次重复蹲守 / 真实环境耐心
- 视觉：动物视角 / 微观视角 / 仰望视角 / 真实呼吸起伏
- 节奏：不卡点 / 自然事件节奏 / 让被摄者自然展开

> ⚠️ **与 cinema 的关键差异**：
> - cinema = **极缓推进**（机位缓慢推进，静态凝视）
> - documentary = **手持真实呼吸**（摄影师真的在移动、真的在呼吸，镜头有自然抖动）
> 两者完全不同——cinema 是电影感，documentary 是真实记录感

## 5. 推荐背景范围

与下列 `背景库/*.md` 文件搭配效果最佳：
- `公园.md`（海派园林 + 自然绿植 + 长镜头跟踪自然）—— 自然感最佳
- `街道.md`（真实街道 + 路沿 + 行道树）—— 城市观察
- `咖啡馆外摆.md`（真实外摆场景）—— 城市生活
- `起居室.md`（自然窗户光透入）—— 室内纪实

避免：`少女INS风卧室.md`（风格化过重）、`厨房.md`（功能性过强）。

## 6. 推荐妆造范围

下列 `化妆间/*.txt` 名称关键词命中可优先：
- 含「古风 / 仙气 / 复古 / 中式 / 旗袍 / 仙侠」—— 时代感强，适合历史纪录片
- 含「清新少女 / 莫兰迪」—— 自然不戏剧化
- 整体偏真实朴素、不追求现代数码鲜艳

具体由 AI 在写作时根据风格后缀词判定。

## 7. 专属禁止（仅本风格内有效）

- ❌ 抖音爆款的高饱和撞色（与 douyin 风混淆）
- ❌ Instagram 的莫兰迪淡彩（与 ins 风混淆）
- ❌ 亚洲电影感的极缓推进凝视（与 cinema 风混淆）
- ❌ 舞台灯 / 追光 / 聚光
- ❌ 戏剧化表演 / 强情绪波动
- ❌ 大特写填满画面（最近距离 ≥ 1.2 米）
- ❌ 数字变焦 / 镜头瞬移
- ❌ 滤镜重 / 后期特效堆叠

## 8. 与工程硬约束的关系

- `指令/约束.md` 的真实感机制化（表情渐变 ≥ 1.2 秒 / 不切镜 / 1× 主摄）**永久生效**
- 本档案与约束.md **天然兼容**——手持真实呼吸感正是约束.md「手持微晃 + 拍摄者呼吸起伏」的延伸
- **重要**：本档案的"长镜头跟踪"与 cinema 的"长镜头凝视"是不同概念——纪录片是摄影师真实移动跟随被摄者，cinema 是机位几乎静止凝视场景
- 保留纪录片的"不表演性"——AI 在写作时应让动作自然展开而非戏剧化编排

## 9. 变体钩子

下一个 documentary 变体（-自然纪录片 / -城市观察 / -人文纪实 / -采访式）可直接复制本骨架，按风格调"光线语言 / 常用元素词 / 推荐背景范围"三段即可。
