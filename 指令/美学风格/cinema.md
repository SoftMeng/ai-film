# cinema.md · 大荧幕电影风格档案

> 亚洲电影感 · 侯孝贤 / 小津安二郎 / 是枝裕和 · 长镜头 + 自然光 + 留白 + 凝视感
> 维度：8

## 1. 美学方向

大荧幕电影美学的**亚洲分支**——以侯孝贤 / 小津安二郎 / 是枝裕和为代表的长镜头流派。**核心是"凝视感"**：固定机位长时间注视一个场景，让观众自己观察、自己感受，不靠剪辑制造情绪。10 秒片段聚焦于一个完整的微小时刻（如饭桌前的几秒凝视），不追求情节推进，追求情绪厚度。

## 2. 颜色基调

- **胶片色**（与 ins 莫兰迪的纯色、douyin 的高饱和形成中间地带）
- 核心色系：
  - 暖灰 / 烟青 / 墨绿 / 旧米色（《海上花》色调）
  - 哑光金色（黄昏 / 油灯 / 木质反射）
  - 暗部偏冷灰蓝（与 ins 暗部偏暖形成反差）
- 配色规则：
  - 低饱和但不"莫兰迪"——更接近真实旧胶片质感
  - 阴影偏青蓝（冷调暗部），高光偏暖（暖调高光）
  - 整体偏复古偏旧，不追求现代数码的鲜艳

## 3. 光线语言

- **自然光独大**（窗户光 / 油灯光 / 黄昏光）—— 室内布光优先采用窗外透光的真实光源
- 大光比（亮处与暗处对比强烈，但光线方向自然）
- 高光偏暖（黄昏感），阴影偏冷（青蓝色）
- 不用任何舞台灯 / 追光 / 霓虹光
- 不用冷白光 / 强暖白光反差
- 暗部保留细节（不像好莱坞大片那样把暗部压死）

## 4. 常用元素词（写作时作为后缀）

- 镜头：长镜头感 / 固定机位 / 静态凝视 / 极缓推进 / 全程不切镜（与约束.md 一致）
- 光线：窗户透光 / 自然光 / 油灯光 / 黄昏光 / 大光比 / 暗部细节
- 构图：远景长焦凝视 / 中景偏静态 / 大景深 / 环境大于人物
- 叙事：留白叙事 / 情绪厚度 / 非情节推进 / 微小时刻 / 省略性叙述
- 节奏：极慢 / 不卡点 / 不强刺激 / 让观众自己观察

## 5. 推荐背景范围

与下列 `背景库/*.md` 文件搭配效果最佳：
- `公园.md`（海派园林 + 复层种植 + 边界后退）—— 长镜头凝视自然
- `起居室.md`（极简现代 + 落地窗）—— 黄昏窗户光
- `阳台.md`（防腐木 + 绿植）—— 静坐凝视
- `少女INS风卧室.md`（米白棉麻）—— 但需避开"INS 莫兰迪"调性
- `咖啡馆外摆.md`（黄昏外摆 + 自然光）

避免：`厨房.md`（功能性强）、`街道.md`（人流喧闹）—— 不利于静态凝视。

## 6. 推荐妆造范围

下列 `化妆间/*.txt` 名称关键词命中可优先：
- 含「古风 / 仙气 / 复古 / 中式 / 红汉服 / 盛唐汉服 / 旗袍」
- 含「莫兰迪」单用（不与 ins 同时引用）
- 配色低饱和但不与 ins 同款
- 整体偏素雅、年代感、胶片质感

具体由 AI 在写作时根据风格后缀词判定。

## 7. 专属禁止（仅本风格内有效）

- ❌ 抖音爆款的高饱和撞色（与 douyin 风混淆）
- ❌ Instagram 的莫兰迪淡彩（与 ins 风混淆）
- ❌ 切镜 / 多机位 / 快剪辑
- ❌ 霓虹色光 / 舞台灯 / 追光
- ❌ 数字变焦 / 镜头瞬移
- ❌ 强情绪波动 / 卡点节奏
- ❌ 大特写填满画面（最近距离 ≥ 1.2 米）

## 8. 与工程硬约束的关系

- `指令/约束.md` 的真实感机制化（表情渐变 ≥ 1.2 秒 / 不切镜 / 1× 主摄）**永久生效**
- 本档案与约束.md **天然兼容**——长镜头 + 不切镜 + 自然光正是约束.md 的延伸
- 重要：电影感 ≠ 切镜。本档案的"电影感"专指**亚洲文艺电影长镜头流派**，不包含好莱坞商业大片的切镜 / 大光比动作戏
