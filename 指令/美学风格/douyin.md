# douyin.md · 抖音风格档案

> 抖音爆款短视频美学 · 高饱和 · 节奏卡点 · 钩子前置 · 短注意力曲线
> 维度：8

## 1. 美学方向

抖音爆款短视频的「视觉冲击 + 节奏强 + 钩子前置」美学语言。**核心是抓住短时间内的强刺激**——3 秒建立钩子、5-8 秒给出转折、15 秒完成情绪闭环。10 秒竖屏片段聚焦于"前3秒钩子"+"中段爆发"+"末段钩子"的三段式结构。

## 2. 颜色基调

- **高饱和度**（与 ins 的低饱和形成反差）
- 核心色系：
  - 高饱和红 / 高饱和橙 / 高饱和黄（激情、活力）
  - 高饱和蓝 / 高饱和紫（神秘、距离感）
  - 高饱和绿 / 高饱和粉（青春、可爱）
- 配色规则：
  - 主色 + 强对比点缀色（撞色感）
  - 不超过 3 个色相，但每个色相都拉高饱和度
  - 局部高光（聚光感 / 舞台追光感）

## 3. 光线语言

- **局部高光 + 强对比阴影**（与 ins 的柔光漫射形成反差）
- 追光 / 聚光 / 侧光打亮局部（尤其是脸部和关键动作）
- 阴影边界相对锐利（与 ins 柔化阴影形成反差）
- 允许少量霓虹色光（粉色 / 蓝色 / 紫色光晕）—— ins 严格禁止，douyin 允许
- 不出现冷白光 / 纯白顶光

## 4. 常用元素词（写作时作为后缀）

- 节奏：动作衔接的精准对位感（BPM 卡点）/ 0.2 秒级节拍偏差
- 视觉：高饱和撞色 / 局部高光 / 强对比阴影 / 钩子前置 / 3 秒悬念
- 构图：紧凑特写 / 大脸填屏（仍受约束.md 不大特写限制）/ 居中对称构图
- 情绪：情绪曲线（铺垫-冲突-高潮-解决）/ 强情绪张力
- 姿态：动作转折处的精准定格 / 戏剧化 pose

## 5. 推荐背景范围

与下列 `背景库/*.md` 文件搭配效果最佳：
- `厨房.md`（中岛 + 撞色橱柜 + 暖光）—— 适合反差剧情
- `起居室.md`（极简 + 大撞色软装）—— 适合生活化爆款
- `街道.md`（店招撞色 + 夜间霓虹）—— 适合街拍风
- `咖啡馆外摆.md`（撞色遮阳伞 + 高饱和花箱）

避免：`公园.md`（自然系低饱和）、`阳台.md`（绿植系偏自然）。

## 6. 推荐妆造范围

下列 `化妆间/*.txt` 名称关键词命中可优先：
- 含「红 / 蓝 / 紫 / 黑 / 撞色 / 红金 / 紫金 / 朋克 / 漆皮」
- 含「Cos / 国风 / 仙侠 / 仙姬 / 红黑」
- 配色高饱和 / 强对比

具体由 AI 在写作时根据风格后缀词判定。

## 7. 专属禁止（仅本风格内有效）

- ❌ 莫兰迪色 / 低饱和 / 哑光棉麻 / 自然米白（与 ins 风混淆）
- ❌ 长镜头 / 留白极简 / 慢节奏 / 自然光独大（与 douyin 快节奏冲突）
- ❌ 文艺片 / 侯孝贤式凝视（与 cinema 风混淆）
- ❌ 全屏素净（必须有撞色 / 高饱和 / 钩子）
- ❌ 全身远景超过 3 秒（必须紧贴特写或中近景）

## 8. 与工程硬约束的关系

- `指令/约束.md` 的真实感机制化（表情渐变/手指/美颜/字幕/滤镜/换装等）**永久生效**，不因本档案而放宽
- 本档案**重新定义了**原抖音爆款的"字幕/滤镜/特效/BGM"等视觉元素：
  - **不出现**画面叠加字幕 / 不出现胶片滤镜 / 不出现后期特效 / 不出现音乐层
  - 但保留爆款美学语言本身：高饱和撞色 / 节奏卡点 / 钩子前置 / 强情绪曲线
- 这是「美学语言」与「平台后期」的区分——本档案只承载美学语言，后期元素由约束.md 永久禁止
