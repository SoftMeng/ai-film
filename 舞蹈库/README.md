# 舞蹈库 · 索引

> 抖音热门舞蹈的真实可执行知识库。**仅当主题含"舞蹈/热舞/卡点舞/抖音舞"等关键词时启用**。
>
> **与动作库的关系**：动作库承载日常互动动作（撩发/偏头/眨眼/坐姿），舞蹈库承载专门舞蹈动作（胯画八/顶胯/Wave）。**职责分离，避免互相污染**。

## 文件清单

| 文件 | 层级 | 条目数 | 用途 |
|---|---|---|---|
| `原子动作.md` | 单拍动作 | 16 | 胯画八、摆胯、顶胯、Wave、isolation、contraction、jazz walk、fan kick 等 |
| `节奏组合.md` | 多拍连招 | 8 | 嘉桐摇、香菜摇、手枪连招、爵士律动卡点连招、爵士顶胯连招等 |
| `上镜表情.md` | 表情搭配 | 6 | 眼神挑逗、咧嘴甜笑、冷淡撩人等 |
| `配套音乐.md` | 节奏型 / BPM | 5 | 慢速/中速/快速/变速/魔性 |

合计 35 条。10 秒舞蹈表演只用 1 节奏组合 + 1 上镜表情 + 1 配套音乐。

## 抽样规则

主指令 Step 2 在舞蹈主题下抽 3 维（不再走"主动作/微动作/弧线"的三维结构）：

- **节奏组合**：`节奏组合.md` 抽 1 条（决定整段舞蹈的骨架）
- **上镜表情**：`上镜表情.md` 抽 1 条（决定舞蹈时的表情基调）
- **配套音乐**：`配套音乐.md` 抽 1 条（决定动作的卡点节奏）

**不抽**：
- `原子动作.md`（仅作节奏组合的内部引用，10 秒表演直接用组合而不是单拍）
- `动作库/微动作.md`（舞蹈主题下不需要"微动作"，舞蹈本身就是大动作）

## 严禁（继承自 `背景库/通用元素/道具禁用清单.md`）

- ❌ 舞台地胶 / 聚光灯 / 烟雾机 / 干冰 / LED 屏幕墙 / 专业音响
- ❌ 任何换脸 / 换装 / 多余饰品
- ❌ 突然爆红的脸颊 / 均匀粉色腮红 / 害羞特效 / 动漫式月牙眼
- ❌ 数字变焦 / 镜头瞬移 / 隐形剪辑
- ❌ 大特写填满画面（最近距离 ≥ 1.2 米）
